# Tic Tac Toe Game 

This is a simple Tic Tac Toe game developed using HTML, CSS, and JavaScript.  
It is a browser-based game where two players can play alternately.

##  Features
- Two-player mode
- Interactive UI
- Winner detection
- Restart game option

## Technologies Used
- HTML
- CSS
- JavaScript
